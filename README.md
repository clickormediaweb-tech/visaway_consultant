# visaway_consultant
Responsive, modern single-page web application for Visaway Consultant Group — an independent visa and immigration documentation consultancy based in Bathinda, Punjab. Built with Tailwind CSS, custom JavaScript animations, interactive country flag matrix, client testimonials, and compliance modals.
# 🌍 Visaway Consultant Group | Official Web Application

A sleek, high-conversion, single-page web application designed and developed for *Visaway Consultant Group*, a premier visa documentation and advisory consultancy located in Bathinda, Punjab.

---

### ✨ Key Features & Highlights
* *Modern Aesthetic & Styling:* Built using *Tailwind CSS* with a custom dark navy and crimson red color palette tailored for professional immigration services.
* *Dynamic Country Selector:* Interactive flag-based destination explorer for Canada, UK, Australia, USA, and Dubai featuring tailored permit criteria and partner matrices.
* *Global Network Visualization:* Animated world map showcasing seamless student and traveler pathways connecting Punjab to global destinations.
* *Client Testimonials & Review Submission:* Integrated success stories and an interactive review submission form directly on the page.
* *Legal Compliance Modals:* Fully functional interactive popups for *Privacy Policy, **Terms & Conditions, and **Immigration Disclaimer*.
* *Responsive Mobile Experience:* Smooth scrolling, floating WhatsApp direct action button, and optimized cross-device layouts.

---

### 🚀 Tech Stack
* *HTML5* & *Tailwind CSS* (via CDN)
* *JavaScript (ES6+)* for interactive UI state management, modals, and scroll animations
* *FontAwesome* for scalable vector icons
* *Google Fonts* (Plus Jakarta Sans)
